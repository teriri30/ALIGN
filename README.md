# reUI 农机作业规划系统

一句话：把无人机拍的田块正射影像丢进去，自动认出再生稻的种植行带，排出一条**对行、少压苗**的收割路径，最后导出成无人收获机能读的路径文件。

主要给再生稻宽窄行田块用，等距种植的田块也能跑。

---

## 下载安装（推荐这种方式）

**第一步**：[点这里下载最新版](https://github.com/teriri30/reUI/releases/latest)

**第二步**：找到 `reUI-Setup-x.y.z.exe`，双击它。

**第三步**：一路点「下一步」，装完桌面和开始菜单就有图标了。

几个说明：

- 装在当前用户目录（`%LOCALAPPDATA%\Programs\reUI`），**不会弹管理员权限**，没管理员账号的电脑也能装。
- 换版本直接双击新安装包覆盖即可，配置不会丢。
- 卸载：「设置 → 应用」里找 reUI，或者开始菜单点「卸载 reUI」。
- **不需要**装 Python、Conda、CUDA、显卡驱动——包里都带好了（CPU 推理版）。

### 不想安装？用便携版

下载 `reUI-Windows-x64-x.y.z.zip`，**完整解压**，双击最外层的 `reUI.exe`。

⚠️ 别把 `reUI.exe` 单独拖到桌面——它要旁边的 `_internal` 文件夹才能跑。

系统要求：Windows 10 / 11，64 位。

---

## 打开之后怎么用

1. 新建项目，选一张**带坐标信息**的 GeoTIFF 正射影像（大疆智图导出的那种就行）。
2. 在图上圈出田块边界。
3. 点「作物识别」，选模型，等它跑完（第一次会慢一些）。
4. 依次做「掩膜优化」→ 确定作业带 → 生成作业线。
5. 作业线列表里把不想要的勾掉，然后点「确认」。
6. 设起点（终点、卸粮点是选填），点「路径规划」。
7. 看一眼碾压评价，没问题就导出（`$PATH` / CSV / KML / JSON）。

左侧任务卡片会告诉你每一步缺什么，卡片上的黄字就是当前卡住的原因。

## 常见问题

**双击没反应，或者被杀毒软件拦了？**
这是没做数字签名的开源软件，Windows 会提示「未知发布者」，点「更多信息 → 仍要运行」就行。360、火绒之类可能直接隔离，加个白名单。

**「路径规划」点不动？**
看卡片上的提示，一般是还没设起点，或者作业线还没点「确认」。

**数据存在哪？**
`%LOCALAPPDATA%\reUI`：配置、缓存、日志、自己训的模型都在这里。升级、卸载都不会动它。

**换电脑怎么迁？**
把这个文件夹连同项目目录一起拷过去就行。

**能用 GPU 吗？**
能。发布包为了兼容性是 CPU 版，想用 GPU 就按下面开发者那节自己构建。

**跑得慢？**
几千万像素的大影像本来就要等几分钟，正常现象。想快就先圈小范围跑通流程。

## 给开发者

环境是 Python 3.10，依赖在 `developer/requirements/`。

```bash
python src/main.py            # 源码启动
bash scripts/test.sh -q       # 全量测试（Git Bash 下用这个，避免 PYTHONPATH 干扰）
python -m compileall -q .     # 语法检查
```

构建 Windows 包：

```bat
build_windows.bat D:\zhl\anaconda\envs\game\python.exe
```

产物在仓库根目录：`reUI.exe` + `_internal\`。

发布新版本只要打个 tag，Actions 会自动跑测试、构建、生成安装包和便携包、发 Release：

```bash
git tag -a v0.1.3 -m "reUI 0.1.3"
git push origin v0.1.3
```

安装包脚本是 `packaging/reUI_setup.iss`（Inno Setup 6，装到当前用户、免管理员），图标由 `packaging/make_icon.py` 生成。

导出的路径文件可以独立复核：

```bash
python src/integrity_check.py path_result.csv.manifest.json --verify-sources
```

## 一点边界说明

<!-- DECISION-008: 科研适用范围与指标含义。修改前阅读 docs/DECISIONS.md。 -->

这是个**科研软件**，不是农机出厂自带的软件：

- 模型结果用于记录当前路径的几何指标（理论碾压率、重复碾压率、覆盖率），是按履带几何模型算出来的理论值，**不能替代下地后的实测碾压调查**。
- 导出的 `$PATH` 只保证文本格式能被终端读取；真能不能自主作业，还得看目标机器和现场条件，并且要有实际执行轨迹和作业后调查作证据。
- 转弯策略（弓形、半圆形、梨形、鱼尾形）是四种固定实现，只做几何校验，不搜索田头偏移，也不宣称是「最优策略」。
- 没有有效 CRS、仿射变换或米制尺度时，不做掩膜处理、路径规划和地理导出；正式导出会同时生成 `.manifest.json`，记录来源、参数和算法版本。
- 自动规划保留最近完成状态和最近 50 步操作历史，田块圈选、掩膜、作业线选择、路径都能逐步撤销/重做。
