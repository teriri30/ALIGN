# ALIGN 使用说明

本说明只描述用户操作。作业带前置算法、界面步骤和论文研究链之间的对应关系见 [研究、算法、界面与田间验证统一流程](RESEARCH_SYSTEM_WORKFLOW.md)。

## 一次完整处理

1. 打开带 CRS 和仿射变换的 GeoTIFF，选择模型并确认田块边界。
2. 点击“AI 识别”，再运行掩膜处理。系统会保留原始掩膜、规整化主体、田头和不确定残差等阶段结果。
3. 在农机参数中填写当前机具尺寸；“农机推荐”只依据影像行带宽度和田头空间给出几何候选。
4. 需要时绘制禁行区并确认农机参数。掩膜处理后，系统先依据宽窄行和等距区证据确定作业带，再点击“生成中心线”从已确定作业带生成候选中心线；随后在“选择中心线”步骤勾选要采用的中心线，取消勾选的中心线会隐藏且不参与路径，再设置起点/可选终点或卸粮点，最后点击“路径规划”统一连接掉头。
5. 在画布或路线编辑器检查作业线和转弯段，最后导出 GeoJSON、CSV、KML、JSON 或 `$PATH`。正式导出会同时生成 manifest；用于无人自主收获收割机时，还应在目标终端导入并记录实际自主执行情况。

## 作业线标定（人工纠偏）

算法把作业线放在它认为的行带中心，但最终是否"压在行上"由现场判断。标定功能把人的判断变成可复用的数据：

1. 先在任务清单完成“生成作业线”，再打开 `工具 → 作业线标定（人工纠偏） → 开始 / 结束标定`。
2. 在图上点住要微调的作业线拖动：**不按 Shift 是整条平移**，**按住 Shift 只纠局部弯曲**；松手立即保存，不需要再点"保存项目"。
3. 标定过的线在界面上立即替换为该线；重新执行"路径规划"后，转弯、覆盖与导出的 `$PATH` 都跟着这条线走，目录项来源显示为人工标定。
4. 右键撤销上一步；再次点击同一菜单退出。选中线后可 `清除当前线标定` 恢复算法中心线。
5. 已有"参考线标注"的桩点可用 `导入参考线为标定线` 直接转成标定线，用于本项目的规划。
6. 需要离线评价算法与人线的差距时，用 `导出标定案例…` 生成案例包，再运行 `python src/centerline_calibration.py --case <案例.json> --out <目录>`。

注意：标定线按当前掩膜算法版本绑定；重新执行作物识别或掩膜优化后，需要重新标定。若标定后发现线整体落到另一条带上（偏移量大且换挡），这属于掩膜分割问题，应先修分割，而不是继续挪中心线。


## 当前实现范围

- 系统先确定作业带，再由宽行作业带生成作业线；窄行作为识别和分类证据，等距宽区按割幅生成平行作业线。
- 弓形、半圆、梨形和鱼尾形转弯均已实现。系统按所选策略生成并校验几何，不搜索田头偏移，也不做转弯策略优化或策略对比。
- 足迹、覆盖率和预计碾压率是二维平面模型的计算结果，用于检查当前路径；农机推荐不包含坡度、土壤、重心或车辆动力学模型。
- “农机兼容测试文件”用于核对 `$PATH` 文本和状态码格式；它与科研路径导出和无人自主收获收割机实际作业记录分开。

## 常见提示

- 没有有效地理配准时，先修正 GeoTIFF，不要继续米制处理。
- 修改影像、模型、掩膜、农机参数、禁行区或转弯策略后，需要重新处理或规划。
- 导出失败时先查看项目日志；界面只显示与当前步骤直接相关的提示。

## 田间自主作业与论文实验资料

论文实验资料不限定为掩膜阶段资料包。不同生育期或不同田块应分别保存源影像、模型、作业带、中心线、路径文件、终端导入记录、实际自主执行轨迹和作业后碾压调查，并保持参数、坐标和文件指纹可追溯。转弯策略优化不由系统自动完成；只有设置独立对照试验时，才对不同策略进行统计比较。
