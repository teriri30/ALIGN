# reUI 使用说明

## 一次完整处理

1. 打开带 CRS 和仿射变换的 GeoTIFF，选择模型并确认田块边界。
2. 点击“AI 识别”，再运行掩膜处理。系统会保留原始掩膜、规则化主体、田头和不确定残差等阶段结果。
3. 在农机参数中填写当前机具尺寸；“农机推荐”只依据影像行带宽度和田头空间给出几何候选。
4. 需要时绘制禁行区、设置起点/可选终点或卸粮点，然后规划路径。
5. 在画布或路线编辑器检查作业线和转弯段，最后导出 GeoJSON、CSV、KML、JSON 或 `$PATH`。正式导出会同时生成 manifest。

## 当前实现范围

- 宽行生成作业线，窄行作为识别和分类证据；等距宽区按割幅生成平行作业线。
- 弓形、半圆、梨形和鱼尾形转弯均已实现。系统按所选策略生成并校验几何，不搜索田头偏移，也不做转弯策略优化或策略对比。
- 足迹、覆盖率和预计碾压率是二维平面模型的计算结果，用于检查当前路径；农机推荐不包含坡度、土壤、重心或车辆动力学模型。
- “农机兼容测试文件”用于核对 `$PATH` 文本和状态码格式；它与科研路径导出分开。

## 常见提示

- 没有有效地理配准时，先修正 GeoTIFF，不要继续米制处理。
- 修改影像、模型、掩膜、农机参数、禁行区或转弯策略后，需要重新处理或规划。
- 导出失败时先查看项目日志；界面只显示与当前步骤直接相关的提示。

## 论文实验资料包

当前默认实验只生成掩膜阶段资料包（原始掩膜、行带重构、主体残差恢复和完整规则化）。转弯策略实验未纳入默认论文范围；如需未来单独研究，应使用冻结输入的离线计划并另行定义评价问题。
