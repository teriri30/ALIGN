```

```

### **改动5：任务提示文字细化**

#### **影像导入**
```
旧："加载正射影像 GeoTIFF 文件。"
新："加载航拍正射影像 GeoTIFF 文件（必须含地理坐标）。"
```
增加"航拍"，更通俗；明确"必须含地理坐标"

#### **作物识别**
```
旧："使用模型分割作物行带。"
新："使用训练好的模型识别作物种植带（像素级分割）。"
```
更准确、更具体

#### **掩膜优化**
```
旧："优化 AI 识别掩膜并提取作物行带。"
新："对识别掩膜去噪、聚合，提取清晰的种植带几何。"
```
去掉"AI"，说明具体操作步骤

#### **终点提示**
```
旧："默认沿最终作业段延伸并写入 TXT；可在画布上拖动调整。"
新："默认沿最终作业段延伸并写入终端文件；可在画布上拖动调整。"
```
"终端文件"比"TXT"更准确
